# 内化设计规范 -- Step5 设计两遍工作法(sansheng-distill)

> **来源与协议**:本文档**内化自 Anthropic frontend-design plugin(Apache 2.0)与 baoyu-design(MIT, Jim Liu)**,把两者的设计方法论压成本 skill 的可判定执行规则。原则归两位上游,落地约束按本 skill 的品牌契约收窄。
> **执行手册,不是审美散文**。管线跑到 Step5(生成 HTML 前的设计定调)时 agent 逐节照做,产出一份「token plan + signature」的设计小结,再据以填 Step6 的槽位。
> **本步只调 `design-craft.md` 允许放开的两成(token 值 / display 字体 / signature),不碰 DOM 契约**(DOM 归 `html-spec.md`)。设计自由度的锁死 / 放开边界以 `brand-tokens.md §5`「品牌锁八成,书魂放两成」表为准 -- 本文档不复述该表,只讲怎么用好那两成。
> 全文破折号一律 `--`;规则给可判定标准,不用「酌情」「适当」。

---

## 1. 两遍工作法(frontend-design 核心)

设计**分两遍**,第一遍出方案,第二遍对抗自审后才动手写 HTML。

### 第一遍 · token plan(为这一本书出一份设计小结)

先把书「钉」在一个具体世界里:领域 + 时代 + 器物 + 行话。distill.json 的 `book_type` / `title` / `author` / `concepts` 就是取材场。然后定三件事:

| 项 | 要求(可判定) |
|---|---|
| **命名色 4-6 个** | 在 `brand-tokens.md §5` 边界内:**底色体系(7 主题全部 token 值)锁死不动**;只对 `--red`/`--blue`/`--green`/`--gold` 四个 accent 做 **oklch 同族微调**(同色相 ±10°,明度饱和小步),使其贴近书的世界。用 4-6 个**命名色**描述你的选择(如「墨绿=常青行业的沉稳 / 铜金=旧账本的金属感」),**只许通过覆盖 token 值实现**,禁新增 token 名、禁组件里写死 hex。**oklch 只是调色 / 换算空间:在 oklch 里调完 accent 后必须换算回 hex(或 rgba)再写进 token 块** -- brand-tokens §7 的 Zero Hex 要求 token 块内是 hex/rgba,不要把 `oklch(...)` 字面写进 CSS |
| **display / body 字体配对** | `--font-body`(正文)**锁死**沿用衬线栈,不换;**只放开 `--font-display`**(标题 / UI):为这本书挑一个有性格的 display 栈,与 body 刻意配对(不是任意项目都用的那套),且**必带 CJK 兜底**(`"Songti SC","Noto Serif SC"` 一类),否则中文静默掉回 sans |
| **signature 元素** | 从书的世界取材的**一个**专属视觉记号(纹样 / 编号体例 / 分隔线肌理 / 字距处理),放在 hero 区,**一页只一个**。它是「换个封面也认得出是这本书」的那处。signature 只落在 hero 的既有槽位内实现(不新增 DOM,html-spec T1) |

> 承 frontend-design:hero 是一个「论点」,开篇亮出这本书世界里最有代表性的东西;结构装置(编号 / eyebrow / 分隔线)要**编码内容里真实存在的信息**,不是装饰 -- 比如编号只在内容确实是有序序列(真流程 / 时间线)时才用。

### 第二遍 · 对抗自审(动手前必须过)

把第一遍方案对着这句话审一遍:

> **「换个人拿类似 prompt 跑,会不会得到同款?」**

- 走一遍「如果只看『把 X 这本书做成蒸馏页』这个泛 prompt,我大概率会产出什么」,凡是**和那个通用默认撞了**的部分(尤其 §2 三俗套、§4 slop 黑名单),**必须改掉**,并一句话记下「改了什么、为什么」。
- **把大胆集中在一处**:让 signature 成为唯一的记忆点,其余一切安静克制;删掉任何不服务于这本书的装饰(Chanel 法则 -- 出门前对镜摘掉一件配饰)。
- 只有确认方案对这本书有辨识度后,才开始按 `html-spec.md` 填 HTML,并**严格照定稿的 token / 字体 / signature 落地**,不即兴发挥。

## 2. 反三俗套(约束 signature 与 display 层)

frontend-design 点名当下 AI 设计最爱撞的三种默认脸,**brief 没点名就不许落入**:

| 俗套 | 长相 |
|---|---|
| 暖奶油衬线陶土 | 近 `#F4F1EA` 暖奶油底 + 高对比衬线大标题 + 陶土色 accent |
| 近黑单一酸绿 | 近黑背景 + 一个高亮酸绿 / 朱红 accent 打天下 |
| 报纸 broadsheet | 发丝细线 + 零圆角 + 密排报纸多栏 |

**本 skill 与「反三俗套」的张力,必须想清楚**:本 skill 默认主题(warm-paper 暖纸典藏)本就是暖纸系 -- 这**不是**落入俗套一,而是**品牌锁死的八成基底**(brand-tokens §5:底色体系全部锁死、是家族感来源,合法且刻意)。所以本条约束的**不是**底色主题,而是**放开的两成**:

- **signature 层**不许再叠加这三种俗套的标志要素(别在暖纸底上再堆陶土 accent + 高对比衬线巨标当「签名」-- 那等于把俗套一又搬了回来)。
- **display 字体层**不许选三俗套的招牌字(见 §4 过度使用字体黑名单)。
- 一句话:**底色系是品牌资产(照用),signature 与 display 是书魂发挥(必须为这本书而独特)**;两者别互相污染。

## 3. CJK 硬规(baoyu-design)

中文正文是主体,以下是硬规:

- **正文 `line-height:1.7-1.8`** -- 密排汉字需要更多纵向空间(骨架已设,填槽别改小)。
- **衬线栈必带 CJK 兜底**:任何「阅读衬线模式」的 `--font-body`/`--font-display` 都要带 `"Songti SC","Noto Serif SC"`(或 `"Noto Serif CJK SC"`)兜底 -- 多数拉丁 reading serif **不含 CJK**,漏了兜底则中文静默掉回 sans,衬线切换在中文上看着像坏了。
- **内容打 `lang` 标**:`<html lang="zh">`(骨架已有);正文默认 zh,内嵌的英文原名 / 引文段可加 `lang="en"`,让浏览器选对字体与断行。
- **中文大标题比同级西文降一档字号** -- 同一层级下,中文方块字视觉重量大于拉丁,西文若与中文并置或作巨标,中文那档字号相对调小一档,避免中文标题过胖压垮版面。

## 4. 反 slop 黑名单(命中即改)

以下是 AI 味浓的套路,**一律禁**(承 baoyu「不加填充内容 / 避免 slop tropes」+ frontend-design 克制原则):

| # | 禁 | 说明 / 豁免 |
|---|---|---|
| S1 | **蓝紫渐变背景** | 攻击性渐变底是最典型 AI slop;背景要氛围走 token 里既定的 `--bg`,别自造花哨渐变 |
| S2 | **emoji 当图标** | 除非是品牌明确的一部分,否则不拿 emoji 充图标 / 项目符号 |
| S3 | **圆角 + 左边框强调色卡片滥用** | 「圆角容器 + 左侧一条 accent 竖线」是 slop 重灾区。**豁免**:`.thesis` / `.quote` 的左边框是本 skill **既有的家族语言**(骨架组件),照用不算违规;禁止的是**新造**一堆这种卡片去装饰 |
| S4 | **凑数数据 / 无用统计** | 不摆没意义的数字、图标、stat(data slop);空区域是**布局问题**,用排版和留白解决,**不是**用编造内容去填(呼应 method / enrich 的不编造铁律) |
| S5 | **手绘 SVG 冒充插图** | 不用手搓 SVG / HTML 假装成一张插画;需要图就用真图(封面 data URI)或留白,别糊一个像素级手绘骗读者 |

> 底线原则:**空白是设计,不是待填的坑**。「这一块看着空」是让布局 / 字号 / 留白去解决的问题,不给它塞凑数内容。

## 5. 布局硬规

- **用 flex / grid + `gap` 排版,禁 inline 流定位** -- 任何一排 / 一组同级元素(按钮、卡片、chips、导航项、表格项)用 `display:flex`/`grid` + `gap:` 给间距,不靠源码空白文本节点或逐元素 margin。flex/grid 间距显式、经得起后续增删重排;inline 流依赖脆弱的空白节点。仅「一句话里夹 `<a>`/`<strong>`/`<em>`」这种文本内联保留。
- **`text-wrap:pretty`** 用在正文段落,避免行尾孤字 / 难看断行(大标题可用 `text-wrap:balance`)。
- CSS 选择器注意 specificity 不要互相抵消(类选择器 `.section` 与元素选择器打架时,section 间 padding/margin 易被覆盖)-- 组件样式沿用骨架既有类,别叠新的高优先级规则去覆盖。

## 6. signature 示例(仅示意,禁直接复用)

给两个「从书的世界取 signature」的示范,**帮助建立取材直觉**,不是让你照抄:

1. **《穷查理宝典》= 格栅报表质感的 display 字距** -- 芒格的世界是财报、格栅化多学科模型;signature 可落在 hero 大标题的 display 字体上,取一种带「表格 / 账簿」感的紧致字距与等宽数字气质,呼应「多学科格栅」意象(只调 `--font-display` + hero 内字距,不动 DOM)。
2. **《金钱心理学》= 存折 / 账本肌理的分隔线** -- 摩根·豪泽尔讲的是钱与人性;signature 可落在 hero 区一条「存折横线 / 账本行格」质感的分隔线上,把「日常账本」的器物感带进页面(用既有分隔元素做肌理,不新造卡片)。

> **示例仅示意,禁直接复用** -- 换一本书就必须换 signature(第一遍从**那本书**的领域 / 时代 / 器物 / 行话重新取材,第二遍对抗自审确认不是通用默认)。把上面两个直接搬到第三本书上,等于违反 §1 第二遍工作法。

## 7. 收尾自查 checklist(Step5 定调完逐条核对)

- [ ] token plan:accent 只做 oklch 同族微调、底色 / 正文字体 / token 名未动(brand-tokens §5);oklch 调完已换算回 hex/rgba 写进 token 块,未把 `oklch(...)` 字面留在 CSS(Zero Hex)。
- [ ] display 字体为这本书专挑、带 CJK 兜底;body 衬线栈未换。
- [ ] signature 只有一个、落在 hero 既有槽位、从书的世界取材。
- [ ] 过了第二遍对抗自审:凡撞通用默认 / 三俗套 / slop 黑名单的都已改,并记下改动理由。
- [ ] 反三俗套的张力已分清:暖纸底是品牌基底(照用),signature/display 没再叠俗套要素。
- [ ] CJK 硬规齐(行高 1.7-1.8 / 衬线 CJK 兜底 / lang 标 / 中文大标题降一档)。
- [ ] slop 黑名单五条无命中;`.thesis`/`.quote` 左边框按家族语言豁免,未新造装饰卡片。
- [ ] 布局用 flex/grid+gap、`text-wrap:pretty`,未用 inline 流定位。
- [ ] 未改 DOM 契约(结构改动一律回 `html-spec.md`,设计只动 token/字体/signature)。
- [ ] 全文 / 页面文案破折号 `--`,无全角 `——`。

**交互出厂检(v3)**(每个可点元素定稿前逐条核对):

- [ ] 点击回报率 ≥3 行 -- 任何点击必须换来至少 3 行新信息;换不来就把内容直接可见,不藏进点击(治 v2「点开只有一句话」)。
- [ ] 交互用于组织,不用于隐藏 -- 筛选 / 分组 / 跳转是好交互(帮读者整理信息);把短内容藏进点击是坏交互,一律改成直接可见。
- [ ] 三问出厂检 -- 每个可点元素须能同时答全「为什么想点 / 点完得到什么 / 怎么回来」三问;三问答不全的交互返工(补明诱因、坐实回报、给回退路径),不合格不出厂。
