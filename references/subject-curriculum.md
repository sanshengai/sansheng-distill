# 学科化：把已蒸书库组织成一门能学完的学科

用户要把某个领域（管理学、心理学、投资等）的已蒸书库做成「一门课」——有总览、有分站、有学习顺序、能从总走到每一本书——时读本页。

**边界**：本页只管「多本书 → 一门学科」的结构与内容方法。
- 只要导航全景、书目与空白：用 [category-framework.md](category-framework.md)。
- 单本书的蒸馏：走 book-reader / book-strict / book-guide 路线，书页按各自路线交付。
- 一个人的一生：走 biography 路线；某人的专题思想：走 person-topic；创作者全部输出：走 creator 路线。
- 同作者或同问题的聚合：走 aggregate 路线。这些路线各自的产物（书页、作品集、专题）只作为学科里的成员与入口被引用，不在本页改写。
- 页面排版、网址与跳转、视觉、上线等产品标准不在本 Skill：由承接该产品的能力规定（「一页」产品见其板块学科化标准）；没有这种能力的环境按当前项目契约。

本页不替代单书路线，也不自动蒸新书。

第一个完整实例是管理学（152 本书，借麦肯锡 7S 分十站）。下面每条写成「何时 → 怎么判断 → 为什么 → 何时不适用 → 怎么验证」，换学科时照做，只在第 1 节的分法上做加法或局部调整。

## 1. 先选骨架：盘点公认分法，给对比，让用户选

- **何时**：开工第一步，写任何站、学派、页面之前。
- **怎么做**：
  1. 盘点这门学科公认的几种分法，每种写出处（教科书、经典文章、权威综述）。管理学盘了十种：职能法、7S 硬软要素、学派法、时代演进、层次法、角色与技能、管理层级、企业生命周期、商学院课程、问题法。心理学大致有：历史取向/学派、现代研究领域（认知、发展、社会、人格、临床…）、层次（生物—个体—社会）、研究方法、应用领域，以及教材通行章节。
  2. 做一张对比表：出处、怎么切、学界认可度、新手好不好懂、从业者能不能对号入座、装不装得下现有书库、要另补哪几块。
  3. 挑 2–3 个能用的方案写清取舍和改动量，**由用户拍板**；只给一个方案或只给结论都不够（用户追问过「还有别的分法吗，我有对比和选择吗」）。
- **一张板只用一把尺子**：时间、地域/传统、体裁（案例、传记）、读者身份不混进主骨架。时间做成生长图或时代视图；地域做成书库筛选；「思想源流」「管理者自身」「本土实践」这类横切内容做成「贯穿各站」的线，不冒充主骨架里的一块。
- **主框架缺的块显式另加**：例如 7S 没有创新与创业，就单列一站并写明「框架之外另加」。不要把缺口硬塞进最近的格子。
- **没选上的分法不扔**：放进总览「这门学科的几种分法」，每种写出处、怎么切、长处与局限，并标出它在本站对应哪几站。读过任何一种教材的人都能对上号，专业读者也能看到选择是有意的。
- **为什么**：凭直觉二分（例如「管事 / 管人」）新手好懂，但经不起专业推敲。它混用了几把尺子，有的格子装了四种东西，有的归属也说不通。
- **何时不适用**：书库只有一两本书的领域只做类别导航，不做学科化。
- **验证**：每站都能说出对应的分法要素；用户能复述为什么选这一种；几种分法各自映射的站都真实存在。

## 2. 层级与数量

- 站 → 学派 → 书。站 8–12 个；每站 1–5 个学派；任何一层同时出现的节点不超过 12 个，一派的书超过 12 本就分组。
- 每本书恰好一个主归属学派（可在别处被引用，不复制正文）。学派 id 稳定，换站只改归属，不改 id。
- 学派有两个名字：新手看得懂的一句话名（「选一个位置，打赢竞争」）和学名（「设计、计划与定位」）。
- 站的编号就是建议的学习顺序。第 1 站如果属于「贯穿线」，排版时单独放在最上面作「起点」，让从上往下读就是 1 → N；不要让第 1 站躲在角落里。
- **验证**：每本书恰好落在一个学派；每层节点数在上限内；编号连续且与排版顺序一致。

## 3. 内容件（一门课要有的东西）

| 件 | 要求 |
|---|---|
| 总览 | 学科是什么、为什么成了一门学问、这里讲什么不讲什么；几种分法；它怎样长成今天这样；按读者情况进入（几站加几本书）；争论预览；每站先读一本 |
| 站 | 它回答的问题；「是什么问题逼出了这一站」（触发与时刻）；3–6 段故事；分出的学派；3 道自检题 |
| 学派 | 新手名与学名、时代、核心问题、概述、关键想法、代表人物、与当下、局限与争议、这一派的书（标先读） |
| 关键想法卡 | 每派 3–5 张；一句白话；出处回到站内的书（本派或相邻学派），引文逐字核对原书；后来的质疑 |
| 人物 | 按站和学派排；一句话写提出了什么 |
| 争论 | 问题、各方立场、各方的书；缺一方的代表作就如实写明「暂未收录」，不拿相近的书凑 |
| 时代 | 按年份分段；每段写重心与回应了什么盲区；书落在原著出版年，年份不明的标待核 |

## 4. 写法口径

- 每一站从「是什么问题逼出了它」讲起，而不是罗列名词。
- 以「站」为单位的产品里，指整个网站不说「本站」，说「这里」，否则读者会读成「这一站」。
- 归类是编者的归纳，不是作者自己的分类，总览里说一次。
- 「与当下」类文字是写作当月的观察，可复看；不写成定论。
- 框架名词要守原意：例如 7S 的「风格」指高层整体的做事方式，借它讲一般领导学时要交代一句。

## 5. 编者新增主张的有界核对

学科化不反向重审成员书。已有书中观点、案例与书目元数据优先复用；编者的问题分类和阅读路径明示为归纳，不为它虚构学派史或作者之间的直接争辩。

只核编者新加、读者可能当作现实事实的主张：新写历史事件、当下统计/机构现状、框架出处及真实引语。按具体对象定点取可靠来源，没有新增此类主张就不派事实复核。新写家长情境可以作为编者示例，不声称实有其人，不为它查真实事件。年份不明可如实留空，不为补满时间轴外查全部书目。

必要核对与写作合并准备材料，输出只记录已发现的实质错误及局部改动；不要求“核对无误清单”、每条正确内容的证明或建议改逐条签署。用户要求独立复核时才另派有界任务；已有检查输入不变就复用。书籍正文及有限年代更新仍按 SKILL.md 执行范围，不扩成原书真假审判。

## 6. 改结构时

- 学派 id 不变，换站只改归属；旧网址一律直接跳到最终位置，不连跳两次；旧地址重新变成正式页面时，从跳转表删掉。
- 书在学科里的位置清单由脚本重生成，书页回链由生成器重刷，不手改产物。
- 文字里依赖旧结构的说法（「这根枝」「主干」「管事」）全文扫一遍，逐条判断，不机械替换。

## 7. 验收

- 从总览只靠点击能到达每一站、每个学派、每一本书；每本书能回到所在学派。
- 关键想法引文、争论各方的书、人物所属学派与数据一致；空缺如实标出。
- 页面形态、视觉、发布由产品与站点能力负责；本页只交付结构、内容与证据。
