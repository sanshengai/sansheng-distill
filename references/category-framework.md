# 类别框架与书目入口（编辑契约，试点阶段）

用户需要心理学、管理学等类别全景与书目导航时读取；要做成一门有分站、学习顺序和自检的完整学科，读 [subject-curriculum.md](subject-curriculum.md)。单书生产不增加此阶段；现役问题专题仍按 topic-craft.md。本文定义编辑边界与增量方式，不声称已有通用类别构建器或生产 schema。

## 1. 三层入口与分类轴

类别全景回答“这个领域研究什么、有哪些主要取向、当前书库覆盖了哪里”；问题专题回答“围绕一个明确问题，各书如何比较”；单书保留原书论证与来源。作者演变是横向入口，不挤进学科分类树。

先核当前书目真实集合、版本与消费者路由，区分已交付成员、交叉候选、尚未覆盖。来源目录存在不等于已蒸完成；本批升级数不等于类别总数。无法确认全库归属就报告已核范围，不凭标签或书名强凑总数。一本书可出现在多个类别入口，引用同一权威书包，不复制正文。

分类轴显式命名。历史学派/思想谱系、现代研究对象、应用领域、具体理论与研究方法不能混作互斥的“几大流派”。可用多张地图，说明组合的编辑目的与不穷尽范围；不要把现有书单反向当成完整学科。背景框架用教材、专业学会或其他可靠原始资料；书籍归类是编者映射，不能升级为作者自认或科学支持。

## 2. 读者应该能做到什么

- 从类别总览看主要问题、不同取向的区别及适用边界；分清事实介绍与编辑组织。
- 看代表人物/观点与可用书目。已蒸、未蒸候选和书库空白分别标明；缺代表书时留空，不借邻近畅销书填满。
- 按研究问题进入专题，再到真实可读的单书页；书页与专题可以回到所属类别。
- 比较相同命题上的分歧、不同层面的互补、平行视角及方法联系。历史对立不自动证明今天具体命题冲突；共享术语不证明支持。书间关系仍遵循 topic-craft.md 的依据、来源硬度与科学裁决边界。

例如心理学的“行为主义”不等于“行为经济学”，认知中的自动加工不等于精神分析的无意识；开放科学通常横贯领域，不另造为一个学派。管理学也应区分历史思想、组织/战略等问题域与方法，不照抄心理学的分区。

## 3. 增量维护与效率

类别框架独立于批次任务，使用显式成员和多重映射；机械书名、作者、版本与路由从单书/网站权威数据读取，认知部分由编辑维护。类别背景来源按版本共享，同一篇研究的实际访问证据可跨关系引用，但各结论仍限定支持范围。

新书完成后只增加其书目、必要领域/专题映射和受影响的关系；未变总论、成员正文与已有效来源复用。类别扩容不自动触发全库重蒸、全书模型审核或重搜整个学科；新的实质分歧再读有关段落与证据。只读归类可以并行，共享索引与最终成员写入串行。

过程记录、去重成本、抽样与停止条件沿 book-batch-operations.md、所选单书路线执行，不另造一套类别正式签署。不把类别更新强制为每本书交付前置；按项目授权的批次里程碑更新。

## 4. 先试点，后推广

先在一个类别做可查看原型：展示分类轴、精确成员、空白、候选身份、关系类型和真实深链。验收读者能从总到分、找到已有书、返回总览；手机可读，筛选无错归属。编辑判断需要真实内容复核，单看 schema 或卡片数量不证明分类正确。

类别只是一两本书时也可做书目与覆盖导航，但不能因此越过专题的三成员门槛，或生成无依据的争议矩阵。试点未接入生产时明确候选状态，不写“已上线”；不为试点改全库单书 schema。

框架与消费者确认后再决定是否抽成通用生成器，新增类别不各写一套重复工具。没有必要的分类变更不再派整包综合模型；新来源版本或新命题改变结论时才更新对应背景/关系。
