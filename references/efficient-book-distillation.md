# 书籍批量蒸馏的效率档

适用：用户明确要求效率优先、接受减少低风险审校，且交付对象是忠实呈现一本书的观点/管理方法。它优化仍有知识分母的管理类既有流程；普通新书默认走完整读者版，不将本文当作第三套叠加审校。企业经营现状、科学证据、医疗法律金融指导、历史人物事实库沿各自核验契约。本档不改变下游产品、数据结构、发布或已有正式闸门。

与完整读者版的边界：本文优化仍有知识分母的管理类既有流水线；用户选择取消细粒度分母/逐项审计、采用一套权威正文时，生产与审阅转用 reader-edition-books.md，不再叠加本文的分母步骤和知识项抽样。通道、成本和复用原则可参考；管理类外查豁免不能跨对象继承。 读者版按章节论证/案例/反例/限制验收，不再叠加本档的5%知识项及30句抽样；在制旧书复用已完成证据；用户取消审阅立即停止，不以旧范围强行续审。

## 1. 开工先明确五件事

记录：交付范围、允许牺牲什么、不可丢的核心内容、审校方式、已有成果及依赖哈希。复用已经合格的来源、图意、模型回执、作者资料、冻结分母和断点；不为了采用效率档重做完成书。不把较低密度签收追溯写成旧书的审校方式。

先阅读真实阶段回执和工具的行为，不凭步骤名判用途。名为fact的模型任务可能只是书内原文忠实性检查，并未联网；来源忠实性、外部真伪验证、当前状态更新三者独立记录。

## 2. 分解所有环节并决定是否值得做

每一大小步骤检查：输入输出、消费者、抓到的真实问题/误报、调用/token/模型墙钟/人工净分钟/排队、重复依赖，以及保留/合并/取消/替代试点。未知成本明确未知。模型报警数不是错误数，减项不是完整性证明，阶段rc0不是内容独立核证。

| 环节 | 保留的结果 | 默认可减少的动作 |
|---|---|---|
| 来源 | 版次/完整范围/原文定位/OCR页段与关键图契约 | 干净电子书绕OCR；规则处理确定项；异常页定点重识别；不重复看同SHA图 |
| 分母 | 知识抽取、核心及条件、来源承接、受控冻结 | 精确去重本地做；归并不为条数好看重跑；缺漏定点补 |
| 分母修补 | 一次忠实初审、分层抽样与高风险裁决 | 模型同响应可提最小修补；不用独立rewrite重述全部，再默认全量audit |
| 正文 | 按相关证据写一次、真实条目链接、非空与结构检查 | 不强迫升华/补时代背景/最低字数；复制扫描留，本地误报豁免；定点fragment修 |
| 检查 | 写出内容忠实与应讲内容覆盖两个独立结果 | 候选：同证据每单元一次联合检查，替代每12句反复发全文；不是删除忠实约束 |
| 补写 | 缺项真假裁决、只修真缺口、变更复验 | 精确插入替换，不整单元返写；同任务哈希和依赖复用 |
| 装配 | 导航/章解释/真实摘录/综合/数据身份 | 从已审内容派生，取消重复全文再讲；外部评价不无源硬填 |
| 验收 | 当前最终输入的覆盖、真实签收、页面/入口和源派生一致 | 相同最终输入不复跑；机器机械环节合一次；页面人工样本按风险及产品规则 |
| 交付 | 私有底本与回执保留、候选归属、准确主线状态 | 归档不阻塞内容评审，批次合回；制作不自动发布 |
| 调度 | 单写者、跨进程真实限流、真实终态与失败缓存 | 整书负责人、不每阶段新建agent；人工积压时不新增审计队列 |

“合并”指保留检查语义、减少重复API或执行，不是把有消费者的输出删掉。未实现的替代必须先用现有正式路径，不用假回执绕过验证器。

## 3. 外部核验与时间敏感内容

管理/方法类书籍如果用户允许取消常规外部事实核查：external_factcheck记录not_applicable及用户决定；不能记录passed。仍查书内归属、否定、数字、因果、关键条件、原话及图意是否忠实。

旧案例、旧统计、职位、市值、预测默认写成作者在成书时的记载/观点；有源年份则带年份，没有年份不编造。只在要输出“现在、仍然、至今”的当前判断，或新增依赖可变事实的操作建议时做temporal_update核查。不能靠出版十年就检查全书每件事；时间词扫描只提示，不证明事实改变。可疑底本记载标“未独立核实”，不悄悄用常识纠正。企业、科学及高后果研究不继承这项豁免。

## 4. 低成本审校与错误收口

普通书机器忠实与覆盖至少各有一轮有效证据；联合实现要完整核输入ID集合、原段及相邻证据，分别报告漏写与失真，不能空报警推定全覆盖。同模型第二轮不是独立人工核证。

普通知识项按章5%分层人工样本，至少20、通常最多80，章节超上限提高到章节数；小书不足20则全取。另审至少30个高风险句（不足则全取），可以复用已审同句但记录真实ID。产品若有更严标准而用户未覆盖，沿产品标准。

影响核心意思/条件、人名归属、数字单位、否定因果、真实摘录、图意及可疑删除的报警实际回源。普通修辞/断句可机器处理并抽样。源裁包集中原句/建议句/差异/PID完整原段/必要邻段/图位置/历史裁决，减少找材料；打包不等于阅读完成。

固定样本错误率>5%、核心错误或跨章系统性错配，暂停该书签收并扩查相关章节/类型；无法定位或扩查持续显示广泛缺陷时走严格全审。保留原失败样本及错误率，不挑样本凑通过。已完成的旧审阅保留真实范围；用户取消全审后不再派审阅任务，不补签未经执行的部分。

复制扫描误报先辨引文/术语/书目；不为消警改书名。fragment编辑精确匹配before、替换唯一定位位置，校验无意外改动，并复验变化来源与覆盖；不接受省略号代替旧正文。只改type而实际模型task和正文不变，可有等价证明复用；改内容则传播失效。正式冻结字段变化走受控修订。

## 5. token及时间管理

优先减少重复任务和前后返工，再缩短输入，最后测试模型推理预算。相关原段与邻段按PID去重；没有必要不重复发整个书/单元；正确内容不逐句长解释；来源集合本地附加并标任务分配范围，不让模型复抄编号冒充语义覆盖；提示用紧凑模板、完整schema留本地校验；不能静默截断证据。

推理参数按当前模型/API真实支持实测，不假定某档位可用。低风险机械任务可试较低推理，复杂语义/图表先保原配置。比较锁定真实源包中的真错/误报/限制遗漏，输出完整度、漏检误删、token和时间；推理token通常是输出子集，不能重复加。减少输出上限导致更多length失败不算节省。

故障只处理失败job；格式能唯一恢复且语义字段不变先本地适配并保留原失败，length先按完整论证拆小失败组，相同原因再次失败不原样盲重试；观察超时先查真实进程/manifest/meta/rc，不能重复启动。usage缺失记未知，不记零；按response_id去重统计。保留套餐通道和跨进程真实并发上限，不擅自改凭证或换按量接口。具体模型/并发/书目留项目配置，不固化成所有项目默认。

## 6. 实施与验收

把优化分为：已验证可直接复用、本批用户授权的降级、需要工具实现与试点的候选。联合检查、fragment模型编辑、抽取内归并、推理配置、人工页面抽样如缺成熟工具，必须作为候选，不宣称已生效。

先改一个高收益小环节，用不同风险的两本普通书试点；不重蒸已完成书作对照。关键检查器改动加入真实路径反例：空输入/漏ID、数字或否定写反、人物错归属、关键条件缺失、无源图意、误删实际案例、改变输入却复用缓存、旧默认被放宽、未做外查却记passed。普通措辞细微错误的取舍明确，不用其豁免核心错误。

每阶段报告模型墙钟、人工净分钟、排队、已知token与未知usage、调用及复用/返工；不要把并行时间相加冒端到端。按源长度/知识项归一化比较，排除来源hold和风险差异。目标吞吐待真实生产批次中位数/P90验证后再排期，不以并发数直接推算每天完成书数。
